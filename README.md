# Package Recolector
Package Recolector is an Editor-only Unity tool intended to simplify the creation of distributable ".unitypackage" files. The user creates or selects a reusable package profile, specifies a package name and author, chooses source folders, and starts an export from a custom Editor window. The tool temporarily builds a folder structure under Assets, copies the selected folders' immediate contents into that structure, exports the temporary author folder as a Unity package, and then attempts to remove the temporary files from the project.
